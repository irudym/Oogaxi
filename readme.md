# *Oogaxi* Reimagined Ugh! game — Modern Game Development in Rust + Bevy: A Complete Course

**Goal:** Build a **modern game on the core idea of *Ugh!*** (physics-driven flying-object gameplay) from an empty folder to a shippable game (native + browser) — with dynamic lighting, shader-driven water, and GPU effects — while learning modern game architecture, not just Bevy APIs.
